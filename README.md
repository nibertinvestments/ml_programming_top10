# Large LLM Programming Project Corpus

This dataset expands into full project bundles and training samples for the top 10 languages.

## Included languages

- Python
- JavaScript
- Java
- C#
- C++
- Go
- Rust
- TypeScript
- PHP
- Ruby

## Included outputs

- large_training_corpus_v2/
- project_bundles_v2/

## Purpose

- Teach LLMs to generate complete projects
- Cover project structure, parsing, APIs, filesystems, memory, and syscalls
- Include low-level assembly and binary samples for each language
